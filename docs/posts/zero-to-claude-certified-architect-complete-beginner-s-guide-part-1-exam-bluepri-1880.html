Zero to Claude Certified Architect — Complete Beginner's Guide ｜ Part 1： Exam Blueprint & Study Plan

A comprehensive breakdown of Anthropic's official credential, detailing the core technology pillars, exam domains, scenario-based questions, and a practical eight-step study plan to pass.

The Anthropic Claude Certified Architect Foundations exam is the official credential validating the skills required to build production-grade AI applications using Claude. Rather than testing theoretical concepts, this exam focuses on practical, scenario-based engineering challenges. Candidates are expected to have at least six months of hands-on experience across Anthropic's developer ecosystem.

The four core technology pillars

The certification evaluates working knowledge across four interconnected technologies:

  • Claude Code: Anthropic's command-line interface for code generation, refactoring, and debugging, configured using claude.md files, custom skills, and Model Context Protocol (MCP) integrations.
  • Agent SDK: The framework used to build multi-agent applications, manage agentic loops, handle sub-agent orchestration, trigger tool calling, and implement lifecycle hooks.
  • Claude API: The foundational HTTP API for programmatic access, specifically focusing on messages.create, tool use, structured JSON output, and the Message Batches API.
  • Model Context Protocol (MCP): The open standard for connecting Claude to databases, APIs, and external services via tool and resource interfaces.

Exam format and scoring mechanics

The exam is structured to test deep, practical understanding rather than rote memorization:

  • Question style: Multiple-choice questions feature one correct answer and three highly plausible distractors designed to catch incomplete knowledge or a lack of familiarity with architectural trade-offs.
  • Scoring: The passing score is 720 on a scaled range of 100 to 1000.
  • No negative marking: There is no penalty for incorrect answers, so candidates should answer every question.
  • Scenario-based pool: The exam randomly selects four scenarios from a pool of six. These scenarios drive the context for the questions.

Exam domains and weightings

Preparation should be prioritized according to the weight of the five core domains:

  1. Agentic Architecture and Orchestration (27%): Covers agentic loops, multi-agent patterns, sub-agent delegation, hooks, and task decomposition.
  2. Claude Code Configuration and Workflows (20%): Focuses on claude.md hierarchy, custom skills, plan mode, and CI/CD integration.
  3. Prompt Engineering and Structured Output (20%): Covers few-shot prompting, tool use patterns, JSON schema design, batch API usage, and validation retry loops.
  4. Tool Design and MCP Integration (18%): Focuses on MCP server design, tool descriptions, tool_choice configuration, and built-in tools.
  5. Context Management and Reliability (15%): Covers escalation decisions, human-in-the-loop triggers, information provenance, and error propagation.

Scenario-based question bank

The exam draws from six distinct production scenarios. Because four are selected at random, candidates must prepare for all of them. Scenarios 1, 3, and 4 are particularly high-density as they span three domains each:

  • Scenario 1 (Customer support resolution agent): Tests agentic architecture, tool design, and reliability.
  • Scenario 2 (Code generation with Claude Code): Tests Claude Code configuration and context management.
  • Scenario 3 (Multi-agent research system): Tests agentic architecture, tool design, and reliability.
  • Scenario 4 (Developer productivity tools): Tests tool design, Claude Code configuration, and agentic architecture.
  • Scenario 5 (Claude Code for CI/CD): Tests Claude Code configuration and prompt engineering.
  • Scenario 6 (Structured data extraction): Tests prompt engineering and context management.

What is and is not on the exam

To optimize study time, candidates should distinguish between in-scope topics and out-of-scope concepts:

In scope

  • Agentic loop implementations (handling stop_reason, processing tool results, and termination conditions).
  • Multi-agent coordinator and sub-agent patterns with proper context passing.
  • The claude.md hierarchy, @import syntax, and path-specific rules using glob patterns.
  • MCP tool and resource design, server configuration, and structured error responses.
  • Structured output via tool_use, schema design, and validation loops.
  • Escalation decisions, human review triggers, and information provenance.

Out of scope

  • Fine-tuning or custom model training.
  • API billing or authentication protocols.
  • Deploying or hosting physical MCP server infrastructure.
  • Constitutional AI or RLHF methodologies.
  • Embedding models or vector database implementations.
  • Computer use, vision analysis, or streaming API implementation details.

An eight-step study plan

  1. Build an agent with the SDK: Write a complete agentic loop featuring tool calling, error handling, sub-agent delegation, and session management.
  2. Configure Claude Code: Practice setting up a full claude.md hierarchy, writing path-specific rules in .clauderules, and creating custom skills with Frontmatter options.
  3. Design and test MCP tools: Practice writing precise tool descriptions that differentiate between similar tools, and implement structured error responses.
  4. Build an extraction pipeline: Use tool_use with JSON schemas, implement validation retry loops, and practice using the Message Batches API.
  5. Practice prompt engineering: Focus on writing few-shot examples for ambiguous scenarios, defining explicit review criteria, and designing multi-pass architectures.
  6. Study context management: Practice extracting structured facts from verbose outputs, using scratchpad files effectively, and managing context during sub-agent delegation.
  7. Review escalation patterns: Learn to identify exactly when a policy gap, a customer request, or an inability to make progress should trigger human review versus autonomous resolution.
  8. Take the practice exam: Complete the practice exam under realistic conditions to familiarize yourself with the scenario-driven question format.
