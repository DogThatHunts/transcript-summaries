Claude Code Tutorial #1 - Introduction & Setup

A step-by-step guide to setting up and using ClaudeCode in your terminal and VS Code for AI-assisted coding.

What is ClaudeCode?

ClaudeCode is an AI-powered agentic coding tool developed by Anthropic. It enables users to analyze, plan, write, and edit code directly within their projects. Unlike tools such as Copilot or Cursor that embed interfaces inside code editors, ClaudeCode operates in the terminal, allowing smoother integration with existing development workflows.

Key features and workflow

  • ClaudeCode runs directly in the terminal, avoiding the need to switch between IDEs.
  • It can integrate with GitHub workflows to automate code reviews on pull requests and provide feedback on open issues.
  • It demonstrates a strong ability to understand the context of a project’s codebase, generating tailored and appropriate code based on specific project needs.
  • The tool supports both local and cloud-based operations, with cloud code accessible via a subscription.

Setup and installation

  • Users must sign up for a Cloud Code account and select a pricing plan: free, Pro ($17/month), or Max (more expensive).
  • The free plan grants access to web and desktop apps but not to ClaudeCode itself.
  • The Pro plan offers usage limits that reset every five hours and includes access to models like Sonic 4 and Opus 4.1.
  • The Opus model consumes usage limits rapidly, so the creator defaults to Sonic 4 for most tasks.
  • The Max plan provides greater usage and access to the latest features as they are released.

Terminal and VS Code integration

  • After installing ClaudeCode globally via npm install -g anthropica.i/claude-code, users navigate to a project directory (e.g., 'shinobi').
  • Running claude inside the terminal starts a session and prompts for a mode (e.g., dark mode) and authentication.
  • Authentication can be completed via console account or subscription, with the Pro plan used in this example.
  • Upon successful login, Claude displays a warning: "Claude can make mistakes—always review its responses, especially code." and advises against prompt injection risks.

Project context and Code review

  • When first used, Claude asks whether the user trusts the files in the project folder. Confirming trust allows the user to begin chatting with the tool.
  • The tool can summarize a project’s structure, such as identifying a Next.js-based blog application with a headless CMS (Content Management System) and learning-focused tech stack.
  • The user emphasizes reviewing generated code manually to maintain control and ensure code quality.

Development environment Setup

  • The tool integrates with VS Code by automatically installing the ClaudeCode extension.
  • The extension adds features like diff viewing, text selection as context, keyboard shortcuts, and active tab awareness.
  • If the extension fails to install automatically, users can manually install it via the Extensions tab.

Git and branch Management

  • ClaudeCode has built-in knowledge of local Git repositories and can execute bash commands.
  • Users can request Claude to switch branches, stage changes, commit, merge, or resolve conflicts.
  • Claude shows the exact bash command it intends to run and requests user permission before execution.
  • The creator sets up a new branch named claude-edits to safely store code changes.

Course and audience access

  • The creator offers early access to the full course via netninja.dev.
  • The course is available for $3 or through a $9/month Net Ninja Pro subscription, which includes early access to all courses and premium masterclasses.
  • A promotional code offers the first month at half price.
