A reference list of every Treasury Decision (TD) cited across the 33 Dave Champion income-tax transcripts, in numerical order, with a link to the source document. Where the IRS hosts the TD directly (a .txt at irs.gov/pub/irs-regs/) that link is the actual document; older TDs are not first-class indexed anywhere, so the link is a HathiTrust full-text search that surfaces the digitized Treasury Decisions Under Internal Revenue Laws volumes. (Same resolver the publisher uses when autolinking citations — see publisher/citations.py.)

"Cited in" gives the Queue row numbers of the videos that reference each TD.

Notes

  • T.D. 8734 and T.D. 8881 are the two modern (1996 / 1998) decisions Champion leans on most — the withholding-on-foreign-persons regulations he reads as proving the tax reaches only non-resident aliens / foreign corporations. 8734 is hosted by the IRS; 8881 is not (confirmed 404 at the IRS path), so it falls back to HathiTrust.
  • T.D. 1928 is the one Champion invokes for "which return form each class of filer uses"; it is pre-1994, so a Federal Register search returns nothing and HathiTrust is the working fallback.
  • T.D. 4707 appears only in the Social Security video (row 1253), tied to the SS-5 application, not the income-tax argument.
  • Champion frequently asserts "nine" / "eleven" Treasury Decisions restrict Form 1040 to non-resident aliens, but enumerates only the numbers listed above; the higher counts are not itemized on-camera.
